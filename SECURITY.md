# Security Policy

## Reporting a Vulnerability

Please **do not** report security vulnerabilities or attach real memory databases, API keys, or conversation transcripts in public GitHub Issues.

Use **[GitHub Private Vulnerability Reporting](https://github.com/HackSing/memware-mcp/security/advisories/new)** to submit a confidential report directly to the maintainers.

Include:
1. Affected product surface (`Memware Cloud`, `Remote MCP`, or `Memware Local CLI` + version/OS).
2. Minimal reproduction steps with redacted credentials and synthetic data.
3. Expected vs. observed security boundary behavior.
